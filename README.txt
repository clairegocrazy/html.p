第 4 週課堂整合練習：Student Dashboard｜學生學習儀表板
版本：W04-PRACTICE-v1

起始專案說明
起始專案已提供完整 Student Dashboard Semantic HTML，以及字型、背景、顏色、邊框、padding 與 margin 等基本視覺樣式。頂部導覽與待辦事項的 Flexbox 尚未完成，Dashboard 主要兩欄 Grid 尚未完成；統計區雖已設定 grid-template-columns，卻缺少啟用 Grid 的必要宣告。此外，Media Query 後方還有一條重複的 .dashboard rule，會覆蓋窄螢幕的單欄設定。學生主要修改 style.css，不需要重新設計 HTML。

開啟方式
1. 將 index.html 與 style.css 放在同一個資料夾。
2. 使用 VS Code 開啟專案資料夾。
3. 使用 Live Server 開啟 index.html，確認 Dashboard 的文字與內容正常顯示。
4. 依功能清單完成 CSS Layout，並觀察不同區塊的排列變化。
5. 使用 DevTools Responsive 模式測試不同 viewport，找出並修正起始專案中的版面問題。

注意：本專案可能含有刻意保留、需要你找出的問題。請依學習單逐步測試。
